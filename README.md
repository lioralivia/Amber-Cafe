Amber Cafe
A clean, responsive website for a local cafe, built entirely from scratch to showcase fundamental web development skills. This project serves as an introduction to structuring web content and styling user interfaces without the reliance on external frameworks or libraries.

Features
Responsive Layout: Adapts to desktop, tablet, and mobile screens.

Menu Showcase: Displays coffee, pastries, and specials using customized image assets.

Visual Aesthetic: Utilizes custom background layers and decorative imagery (like vinyl players and coffee beans) to create an inviting atmosphere.

Clean Code Structure: Emphasizes semantic markup and organized stylesheets.

Built With
HTML5: For semantic structure and content organization.

CSS3 (Vanilla): For custom styling, layouts, and responsiveness.

Getting Started
To view the project locally, you do not need any special development servers or build tools.

Clone this repository to your local machine.

Navigate to the project directory:

Bash
cd Amber-Cafe-main
Open the Main.html file directly in your preferred web browser.
