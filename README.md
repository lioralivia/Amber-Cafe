<h1>Amber Cafe</h1>

<p>A clean, responsive website for a local cafe, built entirely from scratch to showcase fundamental web development skills. This project serves as an introduction to structuring web content and styling user interfaces without the reliance on external frameworks or libraries.</p>

<h2>Features</h2>
<ul>
    <li><strong>Responsive Layout:</strong> Adapts to desktop, tablet, and mobile screens.</li>
    <li><strong>Menu Showcase:</strong> Displays coffee, pastries, and specials using customized image assets.</li>
    <li><strong>Visual Aesthetic:</strong> Utilizes custom background layers and decorative imagery (like vinyl players and coffee beans) to create an inviting atmosphere.</li>
    <li><strong>Clean Code Structure:</strong> Emphasizes semantic markup and organized stylesheets.</li>
</ul>

<h2>Built With</h2>
<ul>
    <li><strong>HTML5:</strong> For semantic structure and content organization.</li>
    <li><strong>CSS3 (Vanilla):</strong> For custom styling, layouts, and responsiveness.</li>
</ul>

<h2>Getting Started</h2>
<p>To view the project locally, you do not need any special development servers or build tools.</p>
<ol>
    <li>Clone this repository to your local machine.</li>
    <li>Navigate to the project directory: <br><code>cd Amber-Cafe-main</code></li>
    <li>Open the <code>Main.html</code> file directly in your preferred web browser.</li>
</ol>
